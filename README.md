# NativeScript Starter App

To jest podstawowy projekt startowy aplikacji mobilnej stworzonej w technologii **NativeScript + Angular**.

## Funkcjonalności

1.  **Ekran startowy:** Wyświetla prosty ekran powitalny z napisem "Hello".
2.  **Struktura projektu:** Przygotowana pod dalszy rozwój z wykorzystaniem Angulara.

## Uruchomienie

1.  Zainstaluj zależności:
    ```bash
    npm install
    ```
2.  Uruchom na Androidzie:
    ```bash
    npx nativescript run android
    ```
